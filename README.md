# enterxera-media-1

Sharded static media repository (`ex_id` **1 – 10,000**) for **EnterXera**, served via jsDelivr CDN.

## Structure
- `posters/{ex_id}.webp` — 2:3 vertical cover posters
- `banners/{ex_id}.webp` — Wide hero banners
- `backdrops/{ex_id}.webp` — 16:9 landscape backdrops
- `logos/{ex_id}.png` — Transparent title logos
- `avatars/characters/{char_id}.webp` — Character avatars
- `avatars/staff/{staff_id}.webp` — Staff & VA avatars
